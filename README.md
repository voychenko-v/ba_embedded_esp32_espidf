# Mini Project: LDR/Potentiometer → Servo Control (ESP32-S3)
 
Рефакторинг навчального проєкту на ESP-IDF: зчитування аналогового сигналу (ADC), фільтрація, мапування в кут сервоприводу та керування через LEDC PWM.
 
## Що робить проєкт
 
- Зчитує напругу з АЦП (потенціометр / фоторезистор) на `ADC_UNIT_2`, канал 6.
- Застосовує SMA (Simple Moving Average) фільтр для згладжування шуму.
- Калібрує сирий код АЦП у мілівольти через `adc_cali_curve_fitting`.
- Мапує напругу → кут сервоприводу (10°–170°) → тривалість імпульсу (500–2500 мкс) → PWM duty cycle.
- Керує сервоприводом через LEDC на GPIO18.
