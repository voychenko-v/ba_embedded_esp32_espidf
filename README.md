# Керування серводвигуном SG90 через потенціометр (ESP32, ESP-IDF)
 
Проєкт демонструє керування кутом повороту серводвигуна SG90 за допомогою аналогового потенціометра на платформі ESP32 з використанням апаратного блоку LEDC для генерації PWM-сигналу.
 
## Як це працює
 
- Серводвигун керується стандартним PWM-сигналом: частота 50 Гц (період 20 мс), а кут повороту визначається тривалістю імпульсу.
- Для даного екземпляра SG90 робочий діапазон тривалості імпульсу підібраний емпірично: **500–2500 мкс** (замість "підручникових" 1000–2000 мкс), що дозволяє отримати повний хід 0–180°.
- Значення з потенціометра зчитується через `adc_oneshot` (ADC2, канал 6, 12-біт), лінійно перераховується в кут 0–180°, а потім у тривалість імпульсу та значення duty для LEDC.
- Напрямок інвертовано програмно: куту 0° відповідає максимальна тривалість імпульсу (2500 мкс), а 180° — мінімальна (500 мкс), щоб відповідність кута фізичному напрямку обертання була зручною для користувача ("як стрілка спідометра").
- Оновлення LEDC відбувається у два кроки — `ledc_set_duty()` записує нове значення в буферний регістр, а `ledc_update_duty()` атомарно застосовує його на межі періоду, щоб уникнути спотворення сигналу посеред імпульсу.
## Апаратне підключення
 
| Компонент        | Пін ESP32 |
|-------------------|-----------|
| Сигнал серво (SG90) | GPIO 18 |
| Потенціометр (виведення) | ADC2, канал 6, GPIO 17 |
| Живлення серво | окреме джерело 5В (спільна земля з ESP32) |
