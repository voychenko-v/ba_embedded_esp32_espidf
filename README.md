# Програвання мелодії на зумері через PWM (ESP32)
 
## Опис завдання
 
Реалізація програвання мелодії "Twinkle, Twinkle, Little Star" на пасивному
п'єзозумері (3-піновий модуль) з використанням апаратного PWM (LEDC) на ESP32,
без FreeRTOS-задач для звуку та без DAC (відсутній на використаній версії ESP32).
 
## Принцип роботи
 
Замість зміни частоти самого PWM-сигналу під кожну ноту, використовується
підхід із програмною генерацією синусоїди:
 
- LEDC генерує ШІМ з **фіксованою несучою частотою 2000 Гц**.
- В таймерному перериванні (`esp_timer`, період = 1/2000 с) на кожному тіку
  беремо значення з таблиці синуса (`sineTable`, 112 точок) і виставляємо
  його як шпаруватість (`duty`) каналу LEDC.
- Індекс у таблиці зсувається на крок `frequencyMultiplier`, розрахований
  під потрібну частоту ноти:
```
  frequencyMultiplier = (частота_ноти * NUM_SAMPLES) / CARRIER_FREQ_HZ
```
 
  Чим більший крок — тим швидше "пробігається" таблиця синуса і тим вища
  ефективна частота відтвореного звуку.
 
## Чому саме 1000 Гц несучої
 
Частота дискретизації (несуча) обиралась за **теоремою Котельникова
(Найквіста)**: щоб коректно відтворити сигнал певної частоти, частота
дискретизації має бути **щонайменше вдвічі вищою** за максимальну частоту
відтворюваного сигналу.
 
Найвища нота в мелодії — `NOTE_A4` (440 Гц). Мінімально необхідна несуча:
 
```
f_несуча ≥ 2 × f_ноти = 2 × 440 = 880 Гц
```
