# Проста ковзна середня (SMA)
Проєкт на ESP-IDF, який зчитує рівень освітленості з фоторезистора (LDR) через ADC, згладжує показники за допомогою алгоритму **Simple Moving Average (SMA)** і керує світлодіодом із застосуванням **гістерезису**, щоб уникнути мерехтіння при незначних коливаннях освітленості.

## Опис завдання

- Підключити LDR до ESP32 у вигляді дільника напруги, вихід якого підʼєднано до одного з каналів ADC1.
- Підключити світлодіод до будь-якого доступного GPIO.
- Реалізувати зчитування значень з ADC у режимі **oneshot**.
- Реалізувати **SMA** для фільтрації значень освітленості.
- На основі відфільтрованих даних:
  - коли стає темно — світлодіод вмикається;
  - коли стає світло — світлодіод вимикається.
- Світлодіод не повинен мерехтіти при незначних коливаннях освітленості (реалізовано через **два пороги гістерезису**).

## Принцип роботи

1. **Зчитування ADC (oneshot режим).** Кожну ітерацію циклу зчитується сире значення з `ADC1_CHANNEL_0` (12-біт, атенюація `ADC_ATTEN_DB_12`).
2. **Фільтрація через SMA.** Кожне нове значення додається до ковзного вікна розміром `WINDOW_SIZE`, найстаріше значення виштовхується. Повертається середнє арифметичне вікна — це згладжує короткочасний шум АЦП.
3. **Прийняття рішення з гістерезисом.** Стан світлодіода реалізовано як скінченний автомат (`LED_OFF` / `LED_ON`) з двома незалежними порогами:
   - `LED_OFF → LED_ON`, коли `sma < SWICH_VALUE - GISTERESIS` (стало темно);
   - `LED_ON → LED_OFF`, коли `sma > SWICH_VALUE + GISTERESIS` (стало світло).
   
   Значення `sma` між цими двома межами не змінює поточний стан — це і є "мертва зона", яка запобігає тремтінню LED при коливаннях освітленості біля порогу.
